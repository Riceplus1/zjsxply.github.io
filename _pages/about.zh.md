我目前是[清华大学深圳国际研究生院](https://www.sigs.tsinghua.edu.cn/)计算机技术专业二年级硕士研究生，导师是[郑海涛副教授](https://scholar.google.com/citations?user=7VPeORoAAAAJ)。我的教育背景涵盖物理、数学、计算机科学和人工智能四门基础学科。

我主要研究算法设计与系统工程如何影响 LLM Agent 的能力与效率。我的论文包括[自然语言的 Agent Harness](https://arxiv.org/abs/2603.25723)，以及对 Agent [自我进化](https://arxiv.org/abs/2510.26852)与[社会进化](https://arxiv.org/abs/2606.03544)能力的研究。

目前，我在百度担任研究实习生，从事[伐谋智能体](https://cloud.baidu.com/product/famou.html)的算法研究。该智能体目前在面向 AutoResearch 任务的 [MLE-Bench](https://github.com/openai/mle-bench) 排行榜上位列第一。我的研究以推动 Agent 实现递归自我改进（RSI）为最终目标。此前，我还曾在美团 [LongCat 基础模型团队](https://github.com/meituan-longcat) 和腾讯[光子工作室群](https://guangzi.qq.com/)实习。

**研究兴趣：**

- **富有洞见与创造力的 Agent**：使 Agent 能够形成关键洞见，突破当前 AI 系统在提出开放式任务解决方案和实现原始创新方面的瓶颈。
- **AI 科学家**：构建自启动的端到端 Agent，使其能够围绕给定的科学主题从零开始开展研究，并产出富有洞见且可验证的科学发现。
- **递归自我改进**：构建能够在真实世界中不断探索和试错，并在 Harness 和 Model 两个层面实现递归自我改进的 Agent 系统。

我还押注基础 LLM 下一阶段的四个重要突破方向：面向开放式主观任务的 AI、计算高效的前沿模型、模型原生的显式知识模块，以及具备真正创新能力的 AI。
